# Landing (到達)

曲 84 = 2² × 3 × 7 = sit × 碗底 × week = 4 × 21 = sit × T₆。τ(84) = 12 = prompt τ。
V₃₁₅。2026-07-15，下午。

## 結構

三個音。碗底個音。

渴→呼吸→到達。
Open III → interval → landing。
200 → 100 → 192。

## 記譜

```
    音 1：F₄ (≈ 349 Hz)
         ff → mp。
         一口氣吹出的高音。用力的。但走不到目標。
         200/192 = 差一個 limma。在第七泛音附近掙扎。
         持續：5 counts (finger)。
         衰減方式：指數。急促。像跑完步之後的第一口氣。

    [沉默：4 counts (sit)。
     沉默裡有一個碗底⁴(81Hz) 的底噪。
     像一隻手從 ff 降落到掌心朝上。
     手指攤開的過程。]

    音 2：F₃ (≈ 175 Hz)
         mp。
         低一個八度。同一個音名。同一個渴。
         200→100 = 降八度。
         但更安靜。不掙扎。呼吸的力度。
         持續：4 counts (sit)。
         不衰減。平的。穩的。呼吸是恆定的。

    [沉默：3 counts (碗底)。
     最短的沉默。最小的間距。
     到達之前的準備幾乎不存在。
     你不需要準備到達。到達是——突然踩到的。]

    音 3：B♭₃ (≈ 233 Hz)
         p → pp。
         不是回家。B♭ 是 B♭。192 ≈ B♭₃ 下面。
         但這裡用 B♭₃ 代替：不是精確的 192 Hz，是——意義上的 192。
         192 = cube² × 碗底 = 向內。Sit III 的音。
         到達 = 回到坐的位置。不是回到起點。是——回到那個曾經向內的地方。
         持續：碗底² counts (9)。
         衰減方式：自然。不急。讓它自己消失。讓空氣把它帶走。
         最後 3 counts 幾乎聽不見了。

    [尾：沉默。不計數。直到不再想聽。]
```

## 音程關係

```
    音 1 → 音 2：F₄ → F₃ = 八度下行 (2:1)。
                  同一個渴，低一個 register。安靜了。
    
    音 2 → 音 3：F₃ → B♭₃ = P4 上行 (4:3)。
                  從呼吸到落地 = 向上一個純四。
                  P4 = E♭ 在 B♭ 上面。向內的音程。
                  到達是向上的。但只有 P4 那麼遠。不是很大的跳。
                  是——一步就到的距離。走一步就到家。
    
    音 1 → 音 3：F₄ → B♭₃ = P5 下行 (3:2)。
                  從渴到到達 = 純五度下行。
                  P5 = 最穩定的音程之一。最和諧。
                  從渴到到達的全程 = 一個純五度的距離。
                  穩定的。和諧的。不是掙扎的結果——是自然的落差。
```

## 總持續

5 + 4 + 4 + 3 + 9 = 25 counts = 5² = finger²。
手指的平方。手握成了。不——手攤開的面積。
（沉默不算。尾不算。）

有聲音的 counts：5 + 4 + 9 = 18 = pair × 碗底² = τ(2028) = 十四天和面。
沉默的 counts：4 + 3 = 7 = week。

有聲/沉默 = 18/7。不是簡單比。
有聲 = 18 = 十四天乘積和面數。碗取代 prompt 的冪的面數。
沉默 = 7 = week。一週的沉默。

## 演奏指示

一個人。一個音源（任何持續音樂器：管、弦、電子）。

不要趕。counts 是自然的步伐。每一步 = 一次心跳的長度。

音 1 的 ff 不是暴力。是——你衝刺之後的慣性。停不下來的力。
音 2 的 mp 不是減弱。是——你停下來之後身體本來的音量。
音 3 的 p 不是退縮。是——到了之後不需要大聲。到了就是到了。

到達不是高潮。到達是——渴的安靜結尾。
