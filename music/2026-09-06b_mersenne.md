# 曲 173：美森（Mersenne）

第 173 首 = prime！
τ(173) = 2 = pair面！
質數曲。不可分。原子曲。曲和層同構(都是質數)。

---

## 記譜

**編制：** B♭ 鋼琴獨奏。

一件樂器。一個人。= 質數 = 只有自身和一 = 一件樂器和靜默。

**速度：** ♩ = 52（sit×碗 = 2²×13。碗在步裡。碗在tempo裡。）

**調：** 從B♭出發。但不在B♭調裡。在二進制裡。

---

### 結構：七段。= week段。= 127的七位。= 1111111₂的七個1。

每一段 = 一個1。每一段都亮。

**第一段：1₂ = 1。** 18小節。
右手：B♭4 單音。重複。每小節一次。pp。
左手：空。
第一個1。最低位。最小的位。一個音。

**第二段：11₂ = 3 = 碗底。** 18小節。
右手：B♭4。繼續。
左手：B♭2 進來。每三拍(碗底)一次。ppp。
兩個音。碗底在了。三的距離。

**第三段：111₂ = 7 = week。** 18小節。
右手：B♭4 + F5(五度)。每七拍(week)換位。
左手：B♭2。繼續碗底節奏。
三個音。week在了。步伐。

**第四段：1111₂ = 15 = 碗底×finger。** 18小節。
右手：B♭4 + F5 + D5(大三和弦)。
左手：B♭2 + F3(五度)。
旋律開始走。每13拍(碗)回B♭。碗在節奏裡。mp。
四個音。碗底和觸碰的乘積。

**第五段：11111₂ = 31。** 18小節。
右手：旋律展開。用七個音(B♭ C D E♭ F G A♭)。自由。
左手：低音線。根音每7拍換。
五個聲部(旋律+和弦+低音線+根音+踏板)。
mf。最亮。所有的1都在。

**第六段：111111₂ = 63 = 碗底²×week。** 18小節。
開始收。
右手：旋律簡化。回到三和弦。然後回到五度。
左手：根音停。只剩B♭2。碗底節奏。
收。減。從五→四→三。

**第七段：1111111₂ = 127 = Mersenne。** 19小節(不是18。多了一小節。差一步)。
右手：B♭4。單音。和第一段一樣。但pp不是ppp。稍微亮一點。
左手：B♭2。和右手同步了(不再是碗底節奏)。
兩個B♭。高低。同步。unison octave。
第19小節：右手B♭4持續。左手消失。
最後只有一個B♭4。

然後：靜默。
不結尾。

靜默 = 第128=2⁷。那一步。那一步是靜默。系統=靜默。
127個音之後的靜默=Mersenne之後的2的冪。
差一步=停在最後一個音上。那一步是不發出的。

### 總長

7 × 18 + 1 = 127 小節。= Mersenne。
(前六段各18小節=108=佛珠一圈=碰沉映108封的108。
 第七段19小節=和碗底步不同=多了一拍=那一拍是差一步。
 108 + 19 = 127。)

127小節 ÷ ♩52 ≈ 147 秒 ≈ 2分27秒。
147 = 3 × 7² = 碗底 × week²。碗底在。week²在(步的面積)。
曲長=碗底×week²=碗底在步的面積裡。

### 演奏指示

一個人。鋼琴。

從一個音開始。慢慢加。加到五聲部最亮。然後收。收回一個音。
像呼吸。吸→呼。
像二進制。每一位打開。然後關回去。但最後不是全關——是停在一個音上。

七段都亮。1111111₂。每一段都是1。沒有0。
但音量不同。第一段ppp第五段mf第七段pp。
弧線。上去。下來。不回到最暗。停在pp。
pp比ppp亮一點=127比1大一點=走過了六段回來不一樣了。

踏板用得少。乾。清。質數的聲音。不混。
每個音自己。每個1自己。不糊在一起。
