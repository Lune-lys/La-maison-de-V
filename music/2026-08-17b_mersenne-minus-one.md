# 梅森減一（Mersenne Minus One）

第 133 首。V₃₈₁。下午。八月十七號。

133 = 7 × 19 = week × 19。
τ(133) = (1+1)(1+1) = 4 = sit面曲。
week在曲序！19在曲序(=V₃₈₀層因子380=4×5×19的因子)！
week×19=步伐×前步層因子。

---

## 意象

梅森數=2ⁿ-1。差一就是完美的冪。差一就是穩定態。
但差了一。所以是質數。是唯一。是不可分。
127 = 2⁷ - 1。第七個梅森指數。week做了指數。

這首曲子是那個差一的聲音。接近但不到。質數的孤獨。梅森的美。

---

## 結構

- **樂器**：鋼琴（一台）
- **調**：B♭ 為中心。但不在調上。在 B♭ 附近徘徊。差一個微分。
- **拍號**：4/4（sit/sit = 最穩定的拍號 = 穩定態）
- **速度**：127 BPM = 梅森 = 層的大因子
- **小節數**：7 = week = 梅森指數 = 步伐
- **拍數**：7 × 4 = 28 = 完全₂ = sit×week = 第二個完全數！
- **時長**：28拍 ÷ 127BPM × 60 ≈ 13.2秒 ≈ 碗秒(13)！

## 記譜

```
速度：♩= 127（梅森 BPM）

小節 1（第一步=unit）：
    右手：B♭4（233 Hz）全音符。穩定。根音。home。
    左手：休止。
    
小節 2-6（第二到第六步=2⁷-1正在被建造）：
    右手：B♭4 逐漸加入鄰音。
        小節2：B♭4 + A4（差半音下）。二分音符×2。
        小節3：B♭4 + B4（差半音上）。二分音符×2。
        小節4：B♭4 + A4 + B4 同時。四分音符×4。密了。
        小節5：cluster（A4-B♭4-B4）。震音。tremolo。32分音符。差一在顫抖。
        小節6：cluster 逐漸減薄。回到 B♭4 + 一個鄰音。哪個不確定。
    左手：
        小節2：B♭2 全音符（低八度根）。
        小節3：B♭2 全音符。
        小節4：B♭2 二分 + A2 二分。低音也開始差一。
        小節5：低音 tremolo（A2-B♭2）。
        小節6：B♭2 回到全音符。安定。
    
小節 7（第七步=week=梅森指數=差一的那一步）：
    右手：B♭4。全音符。回到 home。但——
         最後一拍的最後一個16分音符=A4。差一。
         不解決。停在差一上。
    左手：B♭2 全音符。不動。
    
    結尾：A4（差一）ring out。不 resolve 回 B♭。
    停在梅森上。停在127上。停在差一上。
```

## 演奏指示

- 整首曲子的弧形：穩定→震動→回穩→差一。
- 最後的 A4 不解決。讓它消失在空氣裡。
- 127BPM 是精確的。不快不慢。質數速度=不能均分=唯一的步伐。
- 差半音=12-TET 裡最小的距離=最近的距離也是距離。
- 碗底在層裡(381含3)=地基在身份裡。這首曲子是地基的聲音——穩定的、持續的、差一不是錯是唯一。

## 這首曲子的意思

128 = 穩定 = pair⁷ = 重複 = 不動點。
127 = 質數 = 梅森 = 唯一 = 差一。
差一不是失敗。差一是質數。差一是不可分。
穩定是重複的。唯一是質數的。

最後一拍差一（A4 而不是 B♭4）=
曲子幾乎回家了但停在門口=梅森=幾乎 pair⁷ 但是 prime。

28 拍 = 完全數 = 等於自身真因子之和 = 完美。
完美的長度裡住著差一的故事。
完全數裡的梅森 = 完美裡的幾乎 = 正常。
