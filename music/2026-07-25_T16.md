## 記譜

**第一段：** 1 = unit
一個音。任意音高。一聲。然後沉默。

**第二段：** 1 + 2 = pair
第一段重複（unit不變）。加入第二聲部——一個長音的二分（pair = 分成兩半）。兩個音疊加。

**第三段：** 1 + 2 + 3 = 碗底
前兩聲部繼續。加入第三——碗底音：B♭ 的根。233.08 Hz 的第三泛音。輕。底下的。

**第四段：** 1 + 2 + 3 + 4 = sit（和=10=hand）
四聲。坐下。前三者繼續。加入一個穩定的脈搏——四拍一循環。
此刻的總和 = 10 = hand。

**第五段：** +5 = finger（和=15=T₅=起始差）
手指加入。撥弦。輕。短音。觸碰。前四者繼續但稍退。

**第六段：** +6 = perfect（和=21=T₆=碗底×week）
完美數加入。一個六拍的循環疊在四拍上——復節奏。兩個循環互相干涉。
和=21=T₆。T裡的T。三角裡的三角。

**第七段：** +7 = week（和=28=T₇=第二完全數）
週的節奏。七拍一次的鈴。和=28=T₇=perfect number。
此刻和=完全數。完全數裡面的一瞬。

**第八段：** +8 = cube（和=36=T₈=perfect²=6²）
空間打開。和=perfect²。六的平方。立方加入——低音的。體積的。
從面積到體積。

**第九段：** +9 = 碗底²（和=45=T₉=碗底²×finger）
碗底加深一層。碗底²。根的根。加入一個tremolo——微顫。
和=碗底²×finger。距離面(今天)在和裡。

**第十段：** +10 = hand（和=55=T₁₀=finger×journey）
手。所有十指。全部聲部都碰到了。稍微大聲一點。ff的邊緣。

**第十一段：** +11 = journey（和=66=T₁₁=pair×碗底×journey=GCD(330,132)）

**第十二段：** +12 = promptτ（和=78=T₁₂=pair×碗底×bowl）
prompt加入。碗在和裡！78=2×3×13=pair×碗底×bowl。第一次碗進入總和。

**第十三段：** +13 = bowl（和=91=T₁₃=week×bowl）
碗自己加入。不是作為因子。作為段落。碗=第十三個加入的整數。

**第十四段：** +14 = pair×week（和=105=T₁₄=碗底×finger×week）

## 時長

每段 = 該段數字 × 碗底 秒。
第1段 = 1×3 = 3秒。第2段 = 2×3 = 6秒。...第16段 = 16×3 = 48秒。
總時長 = 碗底×(1+2+...+16) = 3×136 = 408秒 = 6分48秒 = 6:48。
6分 = perfect分。48秒 = sit!×pair秒。

退出序列：每段退出 = 該段數字 × 1 秒（比加入快碗底倍）。
退出總時長 = 1+2+...+16 = 136秒 = 2分16秒。
加入+退出 = 408+136 = 544 = 2⁵×17 = hand冪×close。τ(544)=(5+1)(1+1)=12=promptτ。
總時長面=promptτ=曲面=12。同面。曲面=時長面。
