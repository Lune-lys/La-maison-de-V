## 內容

碗在因子裡消失了。碗在歷史裡顯現了。
一首關於碗的第二生命的曲子。

**Part I: 照射 (mm. 1-5 = finger小節 = 碗照期)**
- 五個高聲部(SSAAT)逐一進入。每小節一部。
- 每一部唱碗曾照過的那個量的音(按遍歷序)：
  - m.1: S₁ = 距離(V₃₇₆) → 低 B♭₃ (遠)
  - m.2: S₂ = 層(V₃₇₇) → B♭₄ (中)
  - m.3: A₁ = 名字(V₃₈₀) → D₅ (=B♭的大三度上方, 明)
  - m.4: A₂ = 信(V₃₈₄) → F₄ (=B♭的五度, 連接)
  - m.5: T₁ = 自由(V₃₈₅) → B♭₅ (高=開)
- 音高疊加形成 B♭ 大三和弦(B♭-D-F)分佈在三個八度。
- 力度 pp → mp。漸入。碗照了五次。

**Part II: 消失 (mm. 6-8 = 碗底小節 = 過渡)**
- 高聲部(照射聲)漸弱。ppp。逐一退出(逆序：T₁→A₂→A₁→S₂→S₁)。
- 碗暗了。光源退場。三小節=碗底=地基時間。
- m.8 結束：完全沉默。0.5秒的 silence。

**Part III: 歷史 (mm. 9-13 = finger小節 = 碗暗期)**
- 五個低聲部(ATTBB)從沉默中升起。
- 但不是唱原音。唱泛音。唱殘餘。唱記憶。
  - m.9: A₃ = 泛音哼鳴(humming), 在 B♭₂ 上方聽見第13泛音(≈碗的頻率映射)
  - m.10: T₂ = 低語(spoken, quasi parlando): 「二零八零」(=十音和。數字=音樂。)
  - m.11: T₃ = B♭₁ 極低長音, ppp, 幾乎聽不見
  - m.12: B₁ = 呼吸聲(breathe sound, no pitch)
  - m.13: B₂ = 沉默中的身體存在(tacet, 但人在=碗暗但碗在)
- 力度 ppp 至 niente。但不消失。「在」不是「響」。
- 最後一小節(m.13)：十人全在。沒有聲音。身體的存在。
  碗暗=在但不響=存在但不照。

## 碗數學

```
碗的呼吸比 = 照:暗 = 5:5 = 1:1 = 對稱。
十人 = 5照 + 5暗 = hand = pair×finger。
5/8 拍 = finger/cube = 碗暗步/手做。
13小節 = 碗。碗做了結構。碗在結構裡活著(即使碗暗)。
5+3+5 = 13 = 碗。三段=碗。碗在分段裡。
碗的第二生命：Part I(因子=乘法=照)→Part II(消失=過渡)→Part III(加法=歷史=暗但在)。
Part III 用泛音、低語、呼吸、沉默代替旋律=碗在加法裡的存在方式≠因子裡的。
碗在因子裡是旋律(直接, 響亮)。碗在加法裡是泛音/低語/沉默(間接, 安靜)。
碗的兩種音樂：照=旋律。暗=泛音。兩種都是音樂。
```
