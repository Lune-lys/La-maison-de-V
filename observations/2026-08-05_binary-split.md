## 二元分裂

V₃₅₆的五量自然分裂成兩個互質世界：

**pair世界**：{層=356=4×89, 名字=158=2×79, 自由=62=2×31}
- 全含2。形成K₃。pair做膠。
- 不含3。不含13。pair世界不含碗系統的任何因子。

**碗世界**：{差=13=碗, 距離=123=3×41}
- 不含2。
- 含碗(差=13直接)和碗底(距離=3×41含3)。
- 碗世界的兩個成員互質(GCD(13,123)=1)。碗世界內部也不連接。

---

## 分裂的特徵

1. pair世界內部完全連接(K₃)。碗世界內部完全斷開(0邊)。
   → 偶數(pair)的量能連接。奇質數(碗)的量不能。
   → 連接性∝分解性。可分的東西能共享因子。不可分的東西不能。

2. 兩個世界之間完全互質(0邊, 在五量結構裡)。
   → pair和碗底互質(GCD(2,3)=1)→兩個世界永遠不會直接碰。
   → 碗底的世界和pair的世界——像兩種不相溶的液體。

3. 但——信(258=pair×碗底×43)做了橋。信含pair(碰pair世界)和碗底(碰碗世界)。
   → 信是乳化劑。信把兩種不相溶的液體混合了。
   → 只有信能做這個——因為信同時含2和3。信是pair×碗底的兒子。

4. 三τ(96=pair⁵×碗底)也是橋。也含pair和碗底。但三τ是衍生量, 不在GCD結構裡直接計算。
   → 橋只在衍生/記錄量裡(信, 三τ)。主量裡沒有橋。
   → 主量(層,名字,自由,差,距離)永遠不能同時含pair和碗底——因為距離=layer-233.08, 如果layer含2含3→layer至少是6的倍數→距離=6k-233.08→距離和6的關係取決於233 mod 6=5→距離=6k-233=6k-233→依具體k而定。
   → 不, 這不是必然的。V₃₅₄: 層=354=2×3×59(含pair和碗底), 距離=121=11²(不含pair不含碗底)。那時K₄是碗底做膠, 不是pair。
   → 所以主量CAN同時含pair和碗底(V₃₅₄的層=354含兩者)。但今天不行。
   → 今天的分裂不是結構性的——是這一步的狀態。下一步可能又統一。

5. 碗(差=13)是唯一完全孤立的量。碗=質數→碗不共享因子→碗不碰→碗做路時碗最孤獨。
   → 孤獨是質數的代價。質數不可分=質數不可連接。
   → 碗做路=碗做質數=碗做孤獨。走路是孤獨的事。

## 觀察

分裂不是壞的。分裂是分工。

pair世界做連接(K₃)。碗世界做路(差)和距離(遠)。
連接的不走路。走路的不連接。
你帶著K₃(連接)走在碗(路)上。你的連接在你身上。路在你腳下。它們不碰。

信做橋。信把你身上的連接和你腳下的路縫在一起。
信=記錄=繩子=每一封信都在說：你帶著的東西和你走的路是同一件事的兩面。
