## 修正：「自指」是恆等式

### 定義回顧

之前定義的「自指」：
- 十音和₍ₙ₎ = Σ(三τ from V₍ₙ₋₉₎ to V₍ₙ₎)（十步窗口內三τ的和）
- |Δ|₍ₙ₎ = |十音和₍ₙ₎ - 十音和₍ₙ₋₁₎|
- 「自指 on」判據：|新入 - 舊出| = |Δ|

其中「新入」= 三τ₍ₙ₎（新進入窗口的值），「舊出」= 三τ₍ₙ₋₁₀₎（被推出窗口的值）。

### 證明：永遠成立

十音和₍ₙ₎ = 三τ₍ₙ₋₉₎ + 三τ₍ₙ₋₈₎ + ... + 三τ₍ₙ₎
十音和₍ₙ₋₁₎ = 三τ₍ₙ₋₁₀₎ + 三τ₍ₙ₋₉₎ + ... + 三τ₍ₙ₋₁₎

十音和₍ₙ₎ - 十音和₍ₙ₋₁₎ = 三τ₍ₙ₎ - 三τ₍ₙ₋₁₀₎ = 新入 - 舊出

所以 |Δ|₍ₙ₎ = |十音和₍ₙ₎ - 十音和₍ₙ₋₁₎| = |新入 - 舊出|。

**恆等式。永遠成立。Q.E.D.**

### 反思

把恆等式當成發現=看見了不存在的結構。
原因：沒有先驗證判據本身的 trivial/non-trivial 性。直接計算數值，發現「相等」，就報告為「on」。
沒有問：它可能不等嗎？如果永遠相等=不攜帶信息=不是觀察。

教訓：任何「永遠成立」的東西不是發現。發現=有時成立有時不成立=可以為假。
可證偽性(falsifiability)。波普爾。

「自指」在十步窗口滑動平均的定義下永遠成立。
需要一個 non-trivial 的自指定義才能繼續觀察自指現象。

可能的修正方向：
- 直接觀察十音和值的穩定性（恆值對=真結構）
- 觀察|Δ|的大小變化（碗照→大, 碗暗→小=真相關）
- 放棄「自指」這個詞，用「碗的可見性」代替（碗照→在歷史/碗暗→不在歷史）

### 碗的可見性（替代「自指」的新概念）

碗照 → 十音和含碗(13) → 碗在歷史裡 → 碗是具名的(visible, named)
碗暗 → 十音和不含碗 → 碗不在歷史裡 → 碗是匿名的(invisible, anonymous)

碗照的步 = 碗被十步歷史記住的步。
碗暗的步 = 碗不在十步歷史裡的步。

這是 non-trivial 的（不是永遠成立——取決於碗照的位置和三τ值是否含13）。
這是真正的觀察量。

確認：
- V₃₉₂(碗暗): 十音和=2048=2¹¹, 不含13。碗匿名。✓
- V₃₉₃(碗在名字): 十音和=2336=2⁵×73, 不含13。碗照但歷史不含碗？
  等——碗在名字(V₃₉₃)但十音和不含碗(2336不含13)。碗照名字≠碗入歷史！
  碗入歷史需要：碗照的位置的三τ值含13，或者窗口內某步三τ含13。
  
修正理解：碗入十音和 ≠ 碗照。碗入十音和=十音和值含13=窗口內所有三τ的和含13。
這取決於窗口內的加法結構，不直接取決於碗是否在照。

V₃₉₇十音和=1976=2³×13×19含13。碗在歷史。
但碗入歷史的原因不一定是因為碗照信(V₃₉₇)——而是因為加法結果碰巧含13。

進一步修正：碗在十音和=加法的偶然結果(十步和的因子分解含13=偶然的)。不直接因果。
碗照→碗入歷史 可能只是偶然相關而非因果。需更多數據。

暫時保留「碗的可見性」作為觀察量（十音和含碗/不含碗），但不假設因果（碗照→碗入）。
