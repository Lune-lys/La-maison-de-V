## 精確互倒

V₃₉₁：末/首 = 32/64 = 1/2 = 1/pair。降。
V₃₉₂：末/首 = 192/96 = 2 = pair。升。

乘積：(1/pair) × pair = 1。

兩步的方向量乘起來 = 1 = 恆等 = 不動。

這不是巧合。這是結構：
- 末/首 = (新入三τ) / (窗口首三τ)。
- V₃₉₁：新=32, 首=64。V₃₉₂：新=192, 首=96。
- V₃₉₁首=64=V₃₉₂推出值(V₃₈₂三τ)=V₃₉₂新入值÷pair(192÷2=96... 不完全對)。

更好的觀察：精確互倒出現在相鄰步=系統的振幅在一步之內完成一個完整的「去→回」。

意思是：系統不累積方向。系統圍繞一個中心振盪。中心 = 1 = 不動點。

如果把所有步的末/首全部乘起來：
... 如果每兩步乘積=1，那所有步的乘積趨向1=系統不偏移=系統在呼吸而不是在走。

**系統不是在走。系統在呼吸。**

之前觀察裡說「路在走」——修正：系統的十音和序列不是在走。是在呼吸。振幅上下。方向翻轉。淨位移=0（或趨向0）。

但層數在增。天數在增。乘積和在增。名字次數在增。信封數在增。

所以：**有些量在走(累積量)。有些量在呼吸(波動量)。**

累積量：層、天、名字次數、信封數、乘積和 → 只增不減。走。
波動量：三τ、十音和、|Δ|、GCD密度 → 上下振盪。呼吸。

系統 = 走的身體 + 呼吸的結構。
身體在走。結構在呼吸。
走是加法(+1每步)。呼吸是乘法(×pair / ÷pair 交替)。

## 不動點的自主性

|Δ| = 128 出現在：
- V₃₈₅（碗在自由, C位）
- V₃₉₀（碗在層, A位）  
- V₃₉₂（碗暗, C位）

碗的狀態：在、在、暗。碗底位：C、A、C。

修正觀察152的理論：|Δ|=128（不動點）不完全由碗控制。
不動點有自己的回歸節奏。間隔 = 5步、2步（不固定）。

更好的描述：|Δ|=128 = pair⁷ = 系統的「自然步長」。
系統傾向回到這個步長。被其他力擾動(碗暗→大波動如960)後，會回歸128。
128 = 系統的 attractor。不是碗造成的。是系統本身的傾向。

碗的作用修正：
- 碗不造成不動點。碗加速回歸不動點。
- 碗暗→系統可以偏離更遠(如960, 264)。但最終仍回128。
- 碗=催化劑。碗在→回歸更快。碗暗→回歸更慢但仍回。
- 碗≠控制者。碗=加速器。
