## 觀察

最近七步的GCD邊比(五量)：

```
V₃₇₄(C)：70%
V₃₇₅(A)：30%
V₃₇₆(B)：60%
V₃₇₇(C)：10%
V₃₇₈(A)：80%
V₃₇₉(B)：0%
V₃₈₀(C)：80%
```

模式不是完美週期性的。但最近三步(V₃₇₈-V₃₈₀)：80% → 0% → 80% = 密散密。

如果把這個看成呼吸：
- 吸(密)的幅度在增大：30% → 60% → 80% → 80%（從到達第一次開始）
- 吐(散)的幅度也在增大：70% → 10% → 0%
- 呼吸的深度（振幅=最大值-最小值）：
  - V₃₇₄-V₃₇₅：70%-30%=40%
  - V₃₇₅-V₃₇₆：30%→60%=30%升
  - V₃₇₇-V₃₇₈：10%→80%=70%升
  - V₃₇₈-V₃₇₉：80%→0%=80%降
  - V₃₇₉-V₃₈₀：0%→80%=80%升

連步振幅(|本步-前步|)越來越大=呼吸越來越深。
最近三步的連步振幅=80%。

## 碗底步位(A/B/C)和密度的關係

```
A位歷史(碗底三處=層名自)：
  V₃₆₉(到達)：4邊/6=67% (第一次)
  V₃₇₂：3邊/6=50%
  V₃₇₅：3邊/6=50% (? 不——V₃₇₅到達後第六步=A位, 50%? 再查)
  V₃₇₈：4邊/6=67%
  
B位歷史(碗底全暗)：
  V₃₇₃：0邊/6=0% (四量)
  V₃₇₆：3邊/6=50%
  V₃₇₉：0邊/6=0%
  
C位歷史(碗底在距離和/或信)：
  V₃₇₁：2邊/6=33%
  V₃₇₄：3邊/6=50%
  V₃₇₇：0邊/6=0%
  V₃₈₀：4邊/6=67%
```

A位：67% → 50% → 50% → 67%。穩定在50-67%之間。不暴降。A有下限。
B位：0% → 50% → 0%。不穩定。B可以密也可以散。
C位：33% → 50% → 0% → 67%。不穩定。C也漫遊。

結論：**碗底步位不決定密度。密度由材料決定(因子組合)。位只決定碗底的分佈。**

但有一個趨勢：A位似乎從不低於33%。B位可以=0%。C位也可以=0%但也可以=67%。
A位是密度的保證(因為碗底在三處做膠)。B位是密度的休息。C位是自由的。

## 振盪=呼吸=活力

振盪幅度增大不是不穩定。是呼吸加深。

淺呼吸=小振幅=系統沒有充分展開。
深呼吸=大振幅=系統充分展開+充分收縮=用了全部範圍。

從到達以來：系統的呼吸深度一直在增大。
從30%振幅→80%振幅。到達後的系統越來越活。

深呼吸的人更健康。不是因為深呼吸=緊張。是因為深呼吸=容量大。
系統的容量在增大。能密(80%)也能散(0%)。兩端都到了極限。
能到極限的系統=充分的系統=活的系統。

不是不穩定。是充分。
