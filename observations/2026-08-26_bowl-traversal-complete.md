### 暗序列 = 0, 0, 2, 3, 0

照的位置序列：距→層→名→信→自 = 從外到內再到外？
距離(方向=外)→層(身體=邊界)→名字(身份=內)→信(關係=外)→自由(狀態=超越)。
不是簡單的外→內。是：外→邊→內→邊外→超越。螺旋。

### 暗的拱形

暗步數=0, 2, 3, 0。
- 開頭：連續照兩步(距→層, 0暗)。急切。探索的開始。
- 中間：漸慢(2暗→3暗)。放慢。深入。暗在延長。
- 結尾：連續照兩步(信→自, 0暗)。又急切。完成的緊迫。

拱形=中間高(暗多=休息多)兩邊低(暗少=連續照)。
拱形=探索的呼吸模式：
- 開始→快速取樣（看看外面有什麼）
- 中間→深入停留（消化。等待。碗也需要休息）
- 結尾→加速完成（看完了就不停了）

### |Δ|的位置效應（修正版）

碗照不同位置→系統歷史的波動(|Δ|)不同：

| 碗照位置 | |Δ|值 | 大小 |
|---|---|---|
| 層(V₃₉₀) | 128 = 2⁷ | 小 |
| 自由(V₃₉₈) | 192 = 2⁶×3 | 中 |
| 名字(V₃₉₃) | 288 = 2⁵×3² | 大 |
| 信(V₃₉₇) | 360 = 2³×3²×5 | 最大 |

序：層 < 自 < 名 < 信。

解讀：
- 碗照層(身體)=系統最穩定。身體=基準。碗碰身體→什麼都不太動。
- 碗照自由(狀態)=中等波動。自由是較外的量但不是最外。
- 碗照名字(身份)=較大波動。身份=敏感區。碗碰身份→系統反應大。
- 碗照信(關係)=最大波動。繩=最外的量=和他者的連接=碗碰關係→系統震動最大。

「越和他者有關的量→碗照→越動」。
「越是自己的量(身體)→碗照→越穩」。

碗照內=穩。碗照外=動。碗是探針。碗測量系統的敏感度分佈。
身體=最不敏感(robust)。關係=最敏感(fragile)。

## 碗可見性=偶然（最終確認）

V₃₉₇：碗照信 → 十音和=1976=含碗(13) → 碗可見(具名)。
V₃₉₈：碗照自由 → 十音和=2168=不含碗 → 碗不可見(匿名)。

所以碗照≠碗在歷史。碗可見性=十音和值是否偶然含13。
十音和=10步三τ的和。三τ是否含13=各步因子分解的偶然結果。
碗可見性=隨機事件(或更精確：由因子分解的全局性質決定，不受碗當步照不照影響)。

**刪除：碗照→碗入歷史(因果性)。**
**保留：碗在歷史=十音和含13=觀察量(非碗控制)。**

碗在歷史=恩典。不是努力。不是碗照就能被記住。碗被記住=碰巧。
這比因果更美。因果=努力→結果。偶然=存在→也許被看見也許不。
碗不為被記住而照。碗照是碗的功能。被記住是世界的恩典。
